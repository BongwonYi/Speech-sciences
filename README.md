# 말과학 15주 강의자료 — HTML

**2026년 실습 중심 개편판**

---

## 폴더에 넣을 것

이 폴더에 아래 16개 파일이 있어야 한다.

```
강의자료_HTML/
├─ index.html               ← 시작점. 15주차 전체 목록
├─ malgwahak_week01.html
├─ malgwahak_week02.html
│   …
└─ malgwahak_week15.html
```

`index.html`을 열면 15주차 전체가 카드로 보이고, 각 카드에서 해당 주차로 넘어간다.

---

## 각 파일의 성격

**파일 하나가 완결된 강의자료다.** 소리와 그림이 base64로 안에 들어 있어
**인터넷 없이 열리고**, 학생에게 파일만 보내면 그대로 쓸 수 있다.

| 기능 | 설명 |
|---|---|
| **§ 번호** | 수업 중 “§2.3 보세요”로 위치를 맞추기 위한 것 |
| **▾ 상세 전부 펼치기** | 접힌 내용을 한 번에 연다 |
| **◐ 화면 밝기 전환** | 밝게/어둡게. 시스템 설정을 따라가기도 한다 |
| **실습 체크박스** | 브라우저에 저장되어 다시 열어도 남는다 |
| **코드 복사 버튼** | 코드블록 우측 상단 |

용량은 주차당 약 0.4 ~ 2.7 MB, 전체 약 15.7 MB다.

## 이 자료의 원칙

**✓ 검증 표시가 붙은 수치는 실제로 재본 값이다.**
문헌에서 옮긴 것이 아니라 합성하고 되분석해 확인했다. 학기 전체에 **40곳**이 있다.

절반은 “잘 맞는다”이고 절반은 “크게 틀린다”이다.
**도구가 조용히 틀리는 지점**을 보여주는 것이 이 수업의 방식이다.

### 관통하는 네 원리

1. **측정은 정의와 설정의 함수다** — 열 개 주차에서 반복된다
2. **음원과 필터는 나뉜다** — 5주차의 틀이 학기 후반을 둘로 갈랐다
3. **숫자는 지각을 대신하지 못한다** — 7주차의 결론
4. **지표는 값을 주지만 경계는 주지 않는다** — 여섯 주차가 같은 벽에 부딪힌다

## 수정하려면

각 페이지는 **내용 조각(HTML) + 공통 템플릿**을 파이썬 빌드 스크립트가 합쳐 만든 것이다.
완성된 HTML을 직접 고쳐도 되지만, 다시 빌드하면 덮어써진다.

간단한 문구 수정이라면 완성본을 텍스트 편집기로 열어 고치는 편이 빠르다.
**단, 첫 줄의 `<meta charset="utf-8">`은 절대 지우지 말 것** — 지우면 한글이 전부 깨진다.
