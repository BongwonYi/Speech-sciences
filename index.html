각 페이지는 파일 하나로 완결된다. 소리와 그림이 전부 안에 들어 있어 인터넷 없이도 열리고, 학생에게 파일만 보내면 된다.

페이지 안에서 ▾ 상세 전부 펼치기로 접힌 내용을 한 번에 열 수 있고, ◐ 화면 밝기 전환으로 밝게/어둡게 바꿀 수 있다. 실습 체크박스는 브라우저에 저장되어 다시 열어도 남아 있다.

Ⅴ이 자료의 원칙

✓ 검증이 붙은 수치는 실제로 재본 값이다

페이지 곳곳의 ✓ 검증 표시는 문헌에서 옮겨 적은 값이 아니라 합성하고 되분석해 확인한 수치라는 뜻이다. 학기 전체에 40곳이 있다.

절반은 “잘 맞는다”이고 절반은 “크게 틀린다”이다. 그것이 정직한 그림이고, 도구가 조용히 틀리는 지점을 학생에게 보여주는 것이 이 수업의 방식이다.

관통하는 네 원리어디서 반복되나
① 측정은 정의와 설정의 함수다1·3·4·6·7·9·11·12·13·14주차 — 열 번
② 음원과 필터는 나뉜다5주차의 틀이 6–7주(음원)와 9–11주(필터)를 갈랐다
③ 숫자는 지각을 대신하지 못한다7주차의 결론이자 이 수업의 윤리적 입장
④ 지표는 값을 주지만 경계는 주지 않는다7·9·10·11·13·14주차가 같은 벽에 부딪힌다
바이브 코딩에 대해

학기 내내 12개의 미션에서 AI에게 코드를 시킨다. 금지하지 않는다. 대신 받은 코드의 결과가 맞는지 판단하는 법을 가르친다.

각 미션에는 확인 방법이 붙어 있다 — “/이/를 넣으면 F1이 300 근처로 나와야 한다”처럼. AI가 자주 틀리는 여섯 지점은 15주차 §3.4에 정리되어 있고, 여섯 가지 모두 코드가 오류를 내지 않는다. 그냥 틀린 값을 준다.
