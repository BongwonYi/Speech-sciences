화자·방언·연령·연구마다 다르다. 특히 /에/–/애/는 현대 서울말에서 합류가 진행되어 젊은 세대에서 구별되지 않는 경우가 많다. 우리 반 데이터로 확인해 볼 좋은 주제다.

모음은 점이 아니다. 앞뒤 자음의 영향(동시조음)으로 포먼트가 계속 움직인다. 그래서 구간 중앙에서 측정하는 것이 관례이고, 이중모음처럼 궤적 자체가 정체성인 경우에는 25 / 50 / 75 % 세 지점을 잰다.

1.4이중모음 — 점이 아니라 화살표다 ★

지금까지는 모음을 F1–F2 평면의 한 점으로 다뤘다. 그런데 한국어 모음의 절반 이상은 이중모음이고, 이것은 점으로 표현되지 않는다.

계열구성예F2 궤적
j계 (ㅑ ㅕ ㅛ ㅠ ㅒ ㅖ)활음 /j/ + 모음야 · 여 · 요 · 유높은 데서 시작해 내려간다
w계 (ㅘ ㅝ ㅙ ㅞ ㅚ ㅟ)활음 /w/ + 모음와 · 워 · 왜 · 웨낮은 데서 시작해 올라간다
ㅢ논란이 있다의/ɰi/ 또는 /ɨj/로 분석
활음은 “아주 짧은 모음”이다

/j/는 조음 위치가 /이/와 거의 같고, /w/는 /우/와 거의 같다. 차이는 지속시간과 안정성이다 — 활음은 머무르지 않고 즉시 다음 모음으로 이동한다.

그래서 /야/의 F2 궤적은 /이/에서 /아/로 가는 선과 거의 같다. 10주차의 포먼트 전이와 같은 현상이다 — 다만 자음의 전이는 40~60 ms로 빠르고, 활음의 전이는 100 ms 안팎으로 느리다.

측정 방법이 달라진다

단모음은 안정 구간 중앙 한 지점에서 재면 된다. 이중모음은 그 한 점이 존재하지 않는다. 계속 움직이기 때문이다.

측정 방식무엇을 얻나
25 / 50 / 75 % 세 지점시작 · 중간 · 끝. 실습 코드가 이미 이렇게 되어 있다
궤적 길이 (Euclidean)F1–F2 평면에서 이동한 거리 — 활음성의 강도
변화율 (Hz/ms)얼마나 빨리 미끄러지는가
중앙 한 지점만쓰면 안 된다. /야/와 /아/가 구별되지 않는다

§3.5의 실습 코드는 이미 25 / 50 / 75 % 세 지점을 뽑도록 되어 있다. 단모음에서는 세 값이 비슷하고, 이중모음에서는 뚜렷이 달라진다. 그 차이 자체가 “이 모음이 이중모음인가”를 판정하는 근거가 된다.

해볼 만한 확장

/이/–/야/–/아/ 세 개를 녹음해 F1–F2 평면에 궤적으로 그려보라. /야/의 궤적이 /이/ 근처에서 출발해 /아/ 근처에서 끝나는지 확인할 수 있다. 점이 아니라 화살표로 그리는 것이 요령이다.

한국어의 /ㅚ/와 /ㅟ/가 단모음인가 이중모음인가는 실제 논쟁거리다. 젊은 세대일수록 이중모음([we], [wi])으로 실현되는 경향이 보고된다. 궤적 길이를 재면 판정할 수 있다 — 14주차 연구 트랙 주제로 좋다.

§2LPC와 측정의 함정

이론 20분 · 오늘 가장 중요한 부분

2.1LPC의 원리

선형예측부호화(LPC)는 현재 표본을 이전 표본들의 선형 결합으로 예측하는 모델이다. 성도를 극(pole)의 집합으로 근사하고, 그 극이 곧 포먼트가 된다.

5주차가 있어야 성립한다

음원은 평탄하다고 가정하고 필터만 추정한다. 그래서 F0가 높아 배음이 성글면 가정이 깨진다.

2.2결정적 설정 두 개 ★

화자Maximum formant
성인 남성5 000 Hz
성인 여성5 500 Hz
아동8 000 Hz 내외

근거 — 성도가 짧을수록 포먼트가 높아진다(5주차 §2.3). 여성은 남성의 약 1.2배다. 이 값을 틀리면 F2와 F3가 통째로 밀린다.

Number of formants는 경험칙으로 1 kHz당 하나다. 상한 5 000 Hz면 5개. 너무 적으면 포먼트를 놓치고, 너무 많으면 없는 봉우리를 만들어낸다(spurious pole).

두 방향의 위험이 대칭이 아니다

상한을 너무 낮게 잡는 쪽이 훨씬 위험하다. LPC가 5 000 Hz까지만 본다고 하면 그 위의 포먼트는 없는 것이 되고, 남은 극들이 아래쪽으로 끌려 내려와 F2·F3가 통째로 밀린다. 그림 1이 그 모습이다.

반대로 상한을 조금 높게 잡으면 대개 값이 크게 틀리지는 않는다. 다만 실제 음성에서는 잡음까지 극으로 잡아 없는 포먼트를 만들어내므로 무작정 올리는 것도 답이 아니다. 확신이 없으면 두 설정으로 재보고 궤적을 눈으로 비교한다.

§3정규화와 모음 공간

이론 20분 · 5주차에서 던진 질문의 답

3.1왜 정규화가 필요한가

성도 길이가 다르면 같은 모음도 다른 값이 나온다(5주차 §2.3). 남성 /이/의 F2가 2 200 Hz라면 여성은 2 600 Hz쯤 된다.

3.2Lobanov 정규화

Lobanov　　z = (F − 화자별 평균) / 화자별 표준편차
방법원리특징
Lobanov화자별 z-점수가장 널리 쓴다. 모음 세트 전체가 필요하다
Bark 차이청각 척도로 변환 후 F3−F2 등화자 정보가 필요 없다
Nearey로그 평균으로 나눈다균일 스케일링을 가정한다
한계

Lobanov는 모든 화자가 같은 모음 세트를 발음했다고 가정한다. 임상에서 한두 모음만 있는 경우에는 쓸 수 없다.

3.3VSA와 FCR

지표정의특징
VSA
모음 공간 면적		꼭짓점 모음의 F1–F2 평면 다각형 면적마비말장애에서 축소된다. 화자 크기에 좌우된다
FCR
포먼트 중앙화 비율		(F2우 + F2아 + F1이 + F1우) / (F2이 + F1아)비율이라 화자 간 비교에 강하다

FCR은 VSA보다 명료도 변량을 약 15 % 더 설명한다는 보고가 있다. 비율이라 성도 길이 차이가 상쇄되기 때문이다. 정규화가 지표 안에 들어 있는 셈이다.

VSA는 어떻게 계산하나 — 신발끈 공식

“다각형 면적”이라고만 하면 실제로 못 구한다. 꼭짓점 좌표만 있으면 신발끈 공식(shoelace formula)으로 한 줄에 나온다.

신발끈　A = ½ · | Σ (xi·yi+1 − yi·xi+1) |　　(마지막 점은 첫 점과 이어진다)
Python VSA와 FCR
import numpy as np

def vsa(points):
    """points: [(F2, F1), ...] 을 다각형 둘레 순서로. 반환 단위는 Hz^2."""
    p = np.asarray(points, float)
    x, y = p[:, 0], p[:, 1]
    return 0.5 * abs(np.dot(x, np.roll(y, -1)) - np.dot(y, np.roll(x, -1)))

def fcr(V):
    """V: {'이': (F1, F2), '아': (...), '우': (...)}"""
    return ((V['우'][1] + V['아'][1] + V['이'][0] + V['우'][0])
            / (V['이'][1] + V['아'][0]))

V = {'이': (280, 2200), '아': (730, 1300), '우': (330, 750)}

# 삼각형 VSA — 꼭짓점을 (F2, F1) 순서로, 둘레를 따라
tri = [(V['이'][1], V['이'][0]), (V['아'][1], V['아'][0]), (V['우'][1], V['우'][0])]
print(f"VSA = {vsa(tri):,.0f} Hz^2")     # 303,750
print(f"FCR = {fcr(V):.3f}")             # 0.908
✓ 검증

단위정사각형에 넣으면 1.0, 가로 3 × 세로 4 직사각형에 넣으면 12.0이 나온다. 위 남성 규준 근사값으로는 VSA 303,750 Hz², FCR 0.908이다.

꼭짓점 순서를 틀리면 면적이 달라진다 — 사각형에서 특히

신발끈 공식은 점을 둘레를 따라 돌면서 넣어야 한다. 순서를 섞으면 도형이 자기 자신을 가로지르는 모양(나비꼴)이 되어 면적이 줄어든다.

네 모음 /이·아·우·으/로 사각형 VSA를 구할 때 실제로 재보면 둘레 순서로 273,000 Hz², 순서를 섞으면 155,250 Hz²다 — 거의 절반이다. 삼각형은 어떤 순서로 넣어도 같아서 이 실수가 드러나지 않는다. 사각형으로 넘어갈 때 처음 걸린다.

FCR은 방향을 헷갈리기 쉽다

FCR은 분모에 모음 공간을 넓히는 값(F2이, F1아)이, 분자에 중앙으로 모으는 값이 들어간다.

FCR이 크다 = 중앙화가 심하다 = 조음이 뭉개졌다. VSA와는 방향이 반대다(VSA는 클수록 넓다). 표에 적을 때 자주 뒤집힌다.

둘 다 조심할 것

청지각 명료도와의 관계가 연구마다 편차가 크다. 단독 지표로 명료도를 예측하려 하면 안 된다.

3.4합류를 어떻게 판정하나 — Pillai 점수

§1.3에서 /에/–/애/ 합류를 언급했고, 실습에서 “갈라지는가?”를 묻는다. 그런데 “갈라진다”를 눈대중으로 판정하면 사람마다 답이 다르다. 사회음성학에서 표준으로 쓰는 도구가 있다.

Pillai 점수 (Pillai score · Pillai–Bartlett trace)

F1과 F2를 동시에 종속변수로 두고 일원 MANOVA를 돌려 얻는 값. 0에 가까우면 두 모음이 완전히 겹친다(합류), 1에 가까우면 완전히 갈라진다.

두 모음 평균 사이의 거리를 재는 것이 아니라 분포의 겹침을 잰다는 것이 핵심이다. 평균이 떨어져 있어도 흩어짐이 크면 실제로는 겹친다.

Python Pillai 점수 — 외부 패키지 없이
import numpy as np

def pillai(A, B):
    """A, B: 각각 (n, 2) 배열. 열은 [F1, F2] (정규화한 값을 쓰는 것이 낫다)."""
    X = np.vstack([A, B])
    gm = X.mean(0)
    H = np.zeros((X.shape[1],) * 2)   # 집단 간
    E = np.zeros_like(H)              # 집단 내
    for Xi in (A, B):
        mi = Xi.mean(0)
        H += len(Xi) * np.outer(mi - gm, mi - gm)
        E += (Xi - mi).T @ (Xi - mi)
    return float(np.trace(H @ np.linalg.inv(H + E)))

부분적으로 겹친다 (/에/–/애/의 현실에 가깝다)0.456
확실히 갈라진다 (/이/ vs /아/ 수준)0.942

경계값이 없다 — 이것을 반드시 알고 쓸 것

“Pillai가 얼마 이하면 합류”라는 공인된 기준은 없다. 연구들은 대개 같은 데이터셋 안에서 화자끼리 비교해 “A가 B보다 더 합류했다”고 말하지, 절대 기준으로 판정하지 않는다.

학기 내내 반복한 이야기가 여기서도 나온다. 지표는 값을 주지만 경계는 주지 않는다. 경계는 사람이 정한다.

Pillai는 표본이 작을수록 위로 편향된다. 오늘 실습에서 모음당 2회만 녹음하면 어떤 모음 쌍이든 갈라져 보인다. 그래서 실습에서는 반 전체를 합쳐 화자별이 아니라 집단 수준에서 본다.

화자 개인의 합류를 논하려면 모음당 최소 10~20 토큰이 필요하다. 이것을 모르고 “나는 /에/와 /애/를 구별한다”고 결론 내리는 것이 가장 흔한 오독이다.

    Python TextGrid 구간의 포먼트 자동 추출
    import os, glob
import numpy as np
import pandas as pd
import parselmouth
from parselmouth.praat import call

MAX_FORMANT = {"male": 5000.0, "female": 5500.0}
POINTS = (0.25, 0.50, 0.75)

def formants_in_intervals(wav, textgrid, tier=1, gender="male"):
    snd = parselmouth.Sound(wav)
    tg  = parselmouth.read(textgrid)
    fo  = snd.to_formant_burg(time_step=0.005, max_number_of_formants=5,
                              maximum_formant=MAX_FORMANT[gender])
    rows = []
    for i in range(1, call(tg, "Get number of intervals", tier) + 1):
        lab = call(tg, "Get label of interval", tier, i).strip()
        if not lab:
            continue
        t0 = call(tg, "Get start time of interval", tier, i)
        t1 = call(tg, "Get end time of interval", tier, i)
        row = {"file": os.path.basename(wav), "gender": gender, "label": lab,
               "dur_ms": round((t1 - t0) * 1000, 1)}
        for p in POINTS:
            t = t0 + (t1 - t0) * p
            for k in (1, 2, 3):
                row[f"F{k}_{int(p*100)}"] = fo.get_value_at_time(k, t)
        rows.append(row)
    return rows

def lobanov(df, f1="F1_50", f2="F2_50", speaker="file"):
    d = df.copy()
    for col in (f1, f2):
        d[col + "_z"] = d.groupby(speaker)[col].transform(
            lambda s: (s - s.mean()) / s.std(ddof=0))
    return d

부록공식과 자주 나오는 질문

핵심 정리

대응　　　F1 ↔ 개구도 (벌릴수록 ↑)　F2 ↔ 전후 (앞일수록 ↑)　F3 ↔ 원순·설측
사각도　　F1 세로 · F2 가로, 두 축 모두 반전
max formant　남 5000 / 여 5500 / 아동 8000 Hz
포먼트 개수　1 kHz당 하나 (상한 5000 → 5개)
실패 조건　F1·F2가 가까움 / F0가 높음 / 비음 / 기식성
이중모음　점이 아니라 궤적. 25 · 50 · 75 % 세 지점을 잰다
　　　　　　j계는 F2 하강 · w계는 F2 상승
Lobanov　　z = (F − 화자평균) / 화자표준편차
VSA　　　꼭짓점 모음 F1–F2 다각형 면적
VSA 계산　신발끈 공식. 꼭짓점을 둘레 순서로 넣을 것
FCR　　　(F2우+F2아+F1이+F1우) / (F2이+F1아)　　클수록 중앙화(나쁨)
Pillai　　0 = 합류, 1 = 분리. 경계값은 없다. 표본이 적으면 위로 편향
검증　　　자동 추출 궤적을 스펙트로그램 위에 겹쳐 눈으로 확인

오늘 챙겨갈 다섯 문장

  1. F1은 개구도, F2는 혀의 전후다.
  2. 포먼트는 배음과 다르다. 음원이 아니라 필터가 만든다.
  3. max formant를 성별에 맞추지 않으면 F2와 F3가 통째로 밀린다.
  4. 자동 추출 결과는 스펙트로그램 위에 겹쳐 눈으로 확인한다.
  5. 정규화 없이 화자 간 포먼트를 비교하면 안 된다.

자주 나오는 질문

포먼트를 몇 개까지 봐야 하나요?

모음 구분에는 F1·F2로 충분하고, 원순성과 /이/ 계열에는 F3가 기여한다. F4 이상은 화자 개인의 성도 모양에 가까워 모음 구분에는 잘 쓰지 않는다.

남녀 데이터를 그냥 같이 그리면 안 되나요?

그리면 성별로 군집이 갈라져 모음 차이가 묻힌다. 정규화하거나 성별을 나눠 그려야 한다. 그림 2의 왼쪽이 그 상황이다.

/에/와 /애/가 안 갈라지는데 제가 잘못 잰 건가요?

아닐 가능성이 높다. 현대 서울말에서 두 모음의 합류가 진행 중이다. 젊은 세대일수록 겹친다. 좋은 미니 연구 주제다. 다만 “갈라진다”고 결론 내리기 전에 토큰 수를 확인할 것 — §3.4의 표본 크기 문제 때문이다.

Pillai가 0.3이면 합류인가요 아닌가요?

그 질문에는 답이 없다. 공인된 경계값이 존재하지 않는다. 같은 데이터 안에서 다른 화자와 비교하거나, 같은 화자의 다른 모음 쌍과 비교해야 의미가 생긴다. 예를 들어 /이/–/아/의 Pillai가 0.94인데 /에/–/애/가 0.30이라면, 그 화자에게 두 쌍의 구별 정도가 확연히 다르다고는 말할 수 있다.

여성·아동 포먼트는 얼마나 믿을 수 있나요?

§2.4의 표가 답이다. F0가 높으면 오차가 20 %를 넘기도 하고, 어떤 F0에서는 F2가 통째로 무너진다. 더 나쁜 것은 오차가 들쭉날쭉하다는 점이다. 한 번 잘 맞았다고 안심할 수 없다. 반드시 스펙트로그램 위에 겹쳐 확인하고, 못 믿겠으면 비워두는 편이 낫다.

LPC 극 개수를 늘리면 더 정확해지나요?

아니다. 늘리면 없는 봉우리를 만들어낸다. 1 kHz당 하나가 경험칙이고, 결과를 눈으로 확인해 조정한다.

VSA가 작으면 명료도가 나쁜 건가요?

경향은 있으나 상관의 강도가 연구마다 크게 다르다. 단독 예측 지표로 쓰지 않는다.
