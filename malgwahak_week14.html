1.3질문을 좁히기 ★

가장 흔한 실패

기술 부족이 아니라 질문이 너무 크다는 것이다.

“한국어 파열음을 분석한다” — 이것은 질문이 아니다.
“20대 서울 화자에서 평음과 격음의 VOT가 겹치는가” — 이것이 질문이다.

점검이렇게 쓰면 안 된다이렇게 쓴다
측정 가능한가“발음이 좋다”“모음 공간 면적(VSA)이 크다”
비교 대상이 있는가“마찰음을 본다”“/ㅅ/과 /ㅆ/의 COG를 비교한다”
모을 수 있는가“60대 화자 30명”“반 학생 16명”
예상이 있는가—“F0 차이가 더 클 것이다. 세대 변화 문헌에 따라”

오늘 첫 15분에 각 조가 자기 질문을 한 문장으로 적고, 1분씩 발표한다. 위 네 가지를 그 자리에서 점검한다.

1.4이 규모로 무엇을 할 수 있나 ★

질문을 좁혔다면 다음 물음은 “우리가 모을 수 있는 자료로 그 질문에 답이 되는가”다. 반 규모는 대개 집단당 8~20명이다. 그 정도로 무엇이 잡히는지 미리 알고 시작하자.

집단당 인원검정력 80 %가 되는 효과크기 dd = 0.5(중간)일 때 검정력d = 0.8(큼)일 때
8명1.5115 %32 %
10명1.3319 %40 %
16명1.0328 %59 %
20명0.9134 %70 %
30명0.7448 %86 %
50명0.5670 %98 %
✓ 검증
읽는 법

집단당 16명이면 d가 1.03은 되어야 80 % 확률로 유의하게 나온다. 그런데 d = 1.0은 매우 큰 차이다 — 10주차에서 본 노년·청년 세대의 VOT 병합 정도가 딱 그 수준(d 4.25 → 1.02)이었다.

뒤집어 말하면, 중간 크기 효과(d = 0.5)는 16명으로 28 %밖에 못 잡는다. 실제로 차이가 있어도 열 번 중 일곱 번은 놓친다.

그래서 프로젝트를 이렇게 설계한다

① 큰 효과가 기대되는 질문을 고른다. 남녀 포먼트 차이, 평음–격음 VOT 차이처럼 이미 크다고 알려진 것이 안전하다. 미묘한 차이를 찾으려는 야심찬 질문일수록 “차이 없음”으로 끝난다.

② 화자 간 비교보다 화자 내 비교를 쓴다. 같은 사람이 두 조건을 다 수행하면(예: 낭독 vs 자유발화) 개인차가 상쇄되어 훨씬 적은 인원으로도 검출된다. 이 수업 규모에서는 이쪽이 거의 언제나 낫다.

③ “유의하지 않았다”를 실패로 여기지 않는다. 위 표를 근거로 “이 표본으로는 d가 1 미만인 차이를 잡을 수 없었다”고 쓰면 그것이 정확한 보고다. 제한점 절에 이 표를 인용할 것.

z점수를 낼 때 — 규준이 작으면 정상인이 이상해 보인다

2단계에서 “규준 대비 편차”를 z점수로 낸다. 계산 자체는 간단하다.

Python 규준 대비 z점수
import numpy as np
import pandas as pd

def z_against_norm(value, norm_values):
    """norm_values: 규준 집단의 측정값 배열 (반 데이터)"""
    ref = np.asarray(norm_values, dtype=float)
    return (value - ref.mean()) / ref.std(ddof=1)

norm = pd.read_csv("class_norms.csv")        # 6~7주차에 모은 반 데이터
case = pd.read_csv("case_measures.csv")      # 사례 화자

for col in ["cpps_dB", "jitter_local_pct", "vsa_Hz2", "artic_rate"]:
    ref = norm.loc[norm.gender == case.gender[0], col]
    z = z_against_norm(case[col][0], ref)
    print(f"{col:<20} z = {z:+.2f}   (규준 n = {len(ref)})")

문제는 규준 표본이 작다는 것이다. 반을 성별로 나누면 집단당 8~16명쯤 된다. 그 정도 표본으로 낸 평균과 표준편차는 그 자체가 흔들리는 추정치다.

완전히 정상인 사람을 규준과 같은 분포에서 뽑아 z점수를 매기는 일을 2만 번 되풀이해 봤다. 이론적으로는 5 %만 |z| > 2로 나와야 한다.

규준 표본 크기|z| > 2 로 찍히는 비율기대값z 분포의 실제 SD
8명10.2 %5 %1.25
12명8.1 %5 %1.15
16명7.1 %5 %1.11
30명6.2 %5 %1.06
100명4.9 %5 %1.02
✓ 검증
규준 8명이면 오경보가 두 배가 된다

정상인 열 명 중 한 명이 “이상”으로 찍힌다. 지표를 네 개 재면 정상인이 적어도 하나에서 걸릴 확률이 훨씬 커진다. 사례 하나에 지표 여러 개를 들이대면서 “이것도 벗어났고 저것도 벗어났다”고 쓰는 것이 이 트랙에서 가장 흔한 과잉 해석이다.

보고할 때는 규준의 n을 반드시 함께 적는다. “z = −2.3 (규준 n = 14)”처럼 쓰면 읽는 사람이 스스로 판단할 수 있다. 9주차 §3.4의 표본 크기 문제와 같은 이야기다.

상황방법
두 집단 비교t-검정 + 효과크기(Cohen's d)
세 집단 이상일원분산분석

강조할 것

p값보다 효과크기와 그림이 중요하다. 표본이 20명 남짓인 수업 프로젝트에서 p값에 매달리지 말 것.

§1.4의 표가 그 이유다. 집단당 20명이면 d = 0.91은 되어야 80 %로 잡힌다. 그보다 작은 차이는 실재하더라도 p > .05로 나올 가능성이 더 크다. 그 상황에서 p값은 “차이가 없다”가 아니라 “이 표본으로는 모른다”는 뜻이다.

보고 형식 — 이렇게 쓴다

“평음과 격음의 VOT 차이는 d = 0.62였으나 유의하지 않았다(t(30) = 1.75, p = .09). 집단당 16명 규모에서 80 % 검정력을 얻으려면 d ≈ 1.0이 필요하므로, 이 결과는 차이가 없다는 근거가 아니라 검출력이 부족했다는 뜻으로 해석해야 한다.”

이렇게 쓰면 만점이다. 효과크기를 보고하고, 표본의 한계를 스스로 짚고, 결론을 데이터가 지지하는 범위 안에 두었다.

이 표를 쓰는 법

말과학은 영어로 speech sciences 다. 교과서도 논문도 Praat의 메뉴도 전부 영어이므로, 한국어 용어만 알면 자료를 찾을 수가 없다.

본문에서 용어가 처음 나올 때 괄호로 영어를 함께 적어 두었다. 이 표는 그것을 한자리에 모은 것이다. 검색할 때는 영어로 하는 편이 압도적으로 낫다.
