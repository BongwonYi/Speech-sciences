4.1환경 점검 — 시험 전 주에 반드시 ★

설치 문제로 시험을 망치는 일이 없어야 한다

아래 스크립트를 자기 노트북에서 돌려 전부 OK가 뜨는지 확인한다. 하나라도 실패하면 시험 전에 해결한다. 당일에 고치려 하면 늦는다.

Python 시험 환경 자가 점검
import sys, importlib, tempfile, os
import numpy as np

print(f"Python {sys.version.split()[0]}")
ok = True

# ① 필수 패키지
for mod in ["numpy", "pandas", "parselmouth", "matplotlib"]:
    try:
        m = importlib.import_module(mod)
        v = getattr(m, "__version__", "?")
        print(f"  OK   {mod:<12} {v}")
    except ImportError:
        print(f"  실패 {mod:<12} -> pip install "
              f"{'praat-parselmouth' if mod == 'parselmouth' else mod}")
        ok = False

# ② parselmouth가 실제로 동작하는가 (import만 되고 죽는 경우가 있다)
try:
    import parselmouth
    from parselmouth.praat import call
    sr = 22050
    t = np.arange(sr) / sr
    snd = parselmouth.Sound(0.5 * np.sin(2 * np.pi * 150 * t), sampling_frequency=sr)

    pitch = call(snd, "To Pitch (cc)", 0, 75, 15, "no",
                 0.03, 0.45, 0.01, 0.35, 0.14, 300)
    f0 = call(pitch, "Get mean", 0, 0, "Hertz")
    print(f"  OK   Pitch 추출      150 Hz 순음 -> {f0:.1f} Hz")
    if abs(f0 - 150) > 2:
        print("       ! 값이 이상하다"); ok = False

    pp = call([snd, pitch], "To PointProcess (cc)")
    rep = call([snd, pitch, pp], "Voice report", 0, 0, 75, 300, 1.3, 1.6, 0.03, 0.45)
    print("  OK   Voice report   " + str(len(rep.split(chr(10)))) + "줄 반환")

    # ③ 파일 입출력
    with tempfile.TemporaryDirectory() as d:
        path = os.path.join(d, "t.wav")
        snd.save(path, "WAV")
        back = parselmouth.Sound(path)
        print(f"  OK   저장/불러오기  {back.get_total_duration():.2f}초")
except Exception as e:
    print(f"  실패 Praat 기능    {type(e).__name__}: {e}"); ok = False

# ④ 한글 경로
try:
    d = tempfile.mkdtemp()
    k = os.path.join(d, "한글폴더")
    os.makedirs(k, exist_ok=True)
    open(os.path.join(k, "가나.txt"), "w", encoding="utf-8").write("ok")
    print("  OK   한글 경로")
except Exception as e:
    print(f"  실패 한글 경로     {e}  -> 영문 경로를 쓸 것"); ok = False

print("\n" + ("모두 통과. 시험 준비 완료." if ok else "실패 항목이 있다. 시험 전에 해결할 것."))
한글 경로에 대해

Praat과 일부 라이브러리는 한글이 섞인 경로에서 파일을 못 읽는 경우가 있다. 시험 당일에는 C:\exam\ 같은 영문 경로에 작업 폴더를 만들 것을 권한다. 해마다 이것 때문에 시간을 버리는 학생이 나온다.

§5모의고사　practice exam

시험 전 주에 혼자 풀어볼 것 · 정답은 접혀 있다

쓰는 방법

정답을 먼저 펼치지 말 것. 아래 소리를 내려받아 실제 시험처럼 재고, 답안지를 채운 뒤에 펼쳐 대조한다. 틀린 것보다 왜 틀렸는지가 중요하다.

이 소리들은 전부 설계값을 아는 합성음이다. 그래서 “진짜 답”이 존재하고, 자기 측정이 맞았는지 스스로 확인할 수 있다.

세 파일 중 하나는 기본 설정으로는 제대로 측정되지 않는다. 어느 것인지, 그리고 왜 그런지가 이 모의고사의 핵심이다.

설계한 F0가 소수점 첫째 자리까지 그대로 회수된다. F0는 신뢰할 만한 값이다. 반면 jitter와 shimmer는 합성할 때 넣은 값과 측정값이 일치하지 않는다 — 넣은 값은 주기 길이의 표준편차이고, 측정값은 이웃한 주기끼리의 차이라 정의가 다르기 때문이다. 그래서 정답은 “설계값”이 아니라 “올바른 설정에서의 측정값”으로 잡는다.

파일 C의 정체

가운데 0.7초 구간에 F0가 62 Hz까지 떨어지는 성문 프라이(vocal fry) 유사 구간을 넣었다. 실제 저음 남성 화자에게서 흔히 나타나는 모습이다.

맞는 대응은 두 가지다. ① floor를 75로 두고 그 구간이 빠진 채로 측정한 뒤 “불안정 구간이 있어 제외했다”고 적는다, 또는 ② 안정 구간만 골라 잘라내고 측정한다. 어느 쪽이든 그 사실을 기록하면 정답이다.

5.2설정을 바꾸면 어떻게 되는가 ★

같은 세 파일을 네 가지 설정으로 측정한 결과다. 이 표가 이 시험이 무엇을 보려는지 가장 잘 보여준다.

세 가지 고장이 한 표 안에 다 들어 있다.

무슨 일이 일어났나왜
B가 109.0 Hz — 정확히 절반옥타브 오류. ceiling 200이 실제 F0 218보다 낮아 Praat이 한 옥타브 아래 주기를 잡았다. 2 : 1로 딱 떨어지면 거의 언제나 이것이다

C가 80.4 Hz, SD 10.1floor 60으로 낮추니 62 Hz 프라이 구간이 포함됐다. jitter도 0.428 → 1.138 %로 2.7배 뛴다. 병리가 아니라 구간 선택의 결과다
A가 어떤 설정에서도 112.0인 것도 함께 볼 것

F0가 안정적인 화자는 설정을 대충 줘도 값이 안 변한다. 그래서 “내 설정이 맞는지” 확인하려고 쉬운 파일로만 시험해 보면 아무 문제도 발견되지 않는다. 설정의 영향은 경계에 있는 화자에게서만 드러난다.

다만 A도 HNR은 25.86 ~ 29.48 dB로 3.6 dB 흔들린다. F0가 멀쩡하다고 다른 지표까지 안전한 것은 아니다.

파트 IV에서 이 이야기를 쓸 수 있으면 만점이다

“이 측정의 한계 세 가지”를 묻는 문항의 모범 답안이 바로 이 표다. 설정 · 과제 · 장비 중 설정에 해당하는 부분을 자기 데이터로 보일 수 있으면 된다.

이 페이지의 정답 음원을 만들면서 F1은 맞는데 F2·F3가 엉뚱하게 나오는 일이 있었다. 원인은 포먼트를 3개만 지정하고 4~6번을 비워둔 것이었다. KlattGrid는 오라 포먼트를 6개 가진 채로 생성되고, 지정하지 않은 포먼트는 사라지는 게 아니라 기본값으로 남아 스펙트럼을 오염시킨다.

6개를 전부 지정하면 해결된다 (예: 700 / 1200 / 2500 / 3500 / 4500 / 5500). AI에게 시키면 보통 3개만 지정하는 코드를 준다. 이번 시험에서 걸리기 쉬운 지점이다.
