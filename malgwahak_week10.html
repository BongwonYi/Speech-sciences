왜 자동 검출이 늦게 잡히나

둘 다 창(window)을 써서 주기성을 판단하기 때문이다. 창 안에 주기가 몇 개는 들어와야 “주기적이다”라고 판정할 수 있으니, 실제 첫 주기보다 항상 늦게 잡힌다. pitch floor를 낮추면 창이 길어져 더 늦어진다(7주차).

그래서 오늘 실습은 손으로 라벨링한다. 자동으로 뽑은 VOT를 문헌값과 비교할 때는 그 문헌이 어떻게 쟀는지를 먼저 확인해야 한다. 몇 ms의 치우침은 평음–격음 병합 여부를 논할 때 결코 작지 않다.

1.4조음 위치와 VOT · place of articulation & VOT

순서　　양순 (ㅂ ㅍ) < 치조 (ㄷ ㅌ) < 연구개 (ㄱ ㅋ)

뒤쪽에서 조음할수록 VOT가 길다. 연구개는 접촉 면적이 넓고 혀 뒤쪽의 질량이 커서 개방이 느리기 때문이다.

실습에서 이걸 확인하는 이유

자기 데이터에서 이 순서가 나오면 측정이 제대로 됐다는 내부 검증이 된다. 안 나오면 라벨링을 다시 본다.

1.5조음 위치는 무엇이 가르나 — 포먼트 전이 ★ · formant transitions & locus

§1.4만으로는 부족하다

조음 위치별 VOT 순서(양순 < 치조 < 연구개)는 경향일 뿐 차이가 작다. 실제로 청자가 “바”인지 “다”인지 “가”인지 아는 것은 VOT가 아니다. 뒤따르는 모음의 포먼트가 어디서 출발하는가로 안다.

locus(자리) 이론

자음의 폐쇄가 풀리는 순간, 성도는 그 조음 위치에 해당하는 모양이다. 거기서 모음의 모양으로 미끄러져 간다. 그 출발점이 locus이고, 미끄러지는 구간이 포먼트 전이(formant transition)다.

5주차 §2.4 섭동 이론의 직접적 귀결이다. 입술을 막으면(양순) 성도가 길어진 셈이라 F2가 낮고, 혀끝을 치조에 붙이면 앞이 좁아져 F2가 높다.

velar pinch — 연구개음을 알아보는 가장 확실한 표시

연구개음에서는 F2와 F3가 서로 가까워져 스펙트로그램에서 집게처럼 모인다. 실측에서 그 간격이 362 Hz로, 양순(1 860)과 치조(1 057)보다 훨씬 좁다.

왜 “locus”가 모음마다 조금씩 다른가

엄밀히 말하면 locus는 고정된 주파수가 아니다. Delattre 등이 제안한 원래 개념은 가상의 수렴점이다 — 여러 모음 앞에서의 전이를 뒤로 연장하면 한 점에서 만난다는 것이다.

치조음은 이 가정이 비교적 잘 맞고(어느 모음 앞이든 F2가 1700~1800에서 출발), 연구개음은 잘 안 맞는다. /기/ 앞에서는 F2가 2000 이상, /구/ 앞에서는 1000 근처에서 출발한다. 혀 뒤쪽이 닿는 지점 자체가 모음에 따라 앞뒤로 움직이기 때문이다.

그래서 연구개음은 F2 값보다 velar pinch(F2·F3 근접)로 판별하는 편이 안정적이다. 실습에서 자기 데이터로 확인해 볼 것 — /가/ /기/ /구/ 세 개면 충분히 보인다.

2.3왜 자음이 모음의 F0를 흔드나 · consonantal F0 perturbation

자음에 의한 F0 섭동은 범언어적 현상이다.

  • 성대를 긴장시켜 조음하는 자음(경음·격음) 뒤에는 F0가 높게 시작한다
  • 성대가 이완된 자음(평음) 뒤에는 낮게 시작한다
  • 이 효과는 후속모음 시작 후 약 50–100 ms 안에 사라진다
그래서 측정 지점이 중요하다

모음 시작 직후 짧은 구간(예: 20 ms)에서 잰다. 너무 늦게 재면 효과가 이미 사라진다.

§3진행 중인 변화　a change in progress

이론 15분 · 교과서가 아니라 지금 벌어지는 일

3.1VOT 병합과 단서 이동 · VOT merger

서울말에서 일어나는 일

평음과 격음의 VOT 차이가 줄어들고, 대신 F0 차이가 커지고 있다.

세대VOT 대립F0 대립
1930년대생크다작다
→ 점진적 변화 →줄어든다커진다
1980년대생거의 병합주된 단서

Kang(2014)의 코퍼스 연구가 1930~1980년생 서울 화자를 대상으로 이 변화를 문서화했다. 1960년 이후 출생 화자는 모두 어두 F0 대립의 변화를 보였고, 그보다 앞서 1940년대생 여성 일부에게서 이미 변화가 시작되어 있었다. 여성이 남성보다 앞선다 — 여성 주도 변화의 전형적 양상이다.

단서가 사라진 것이 아니라 옮겨간 것이다

노년 화자는 VOT 하나로 평음과 격음을 갈랐다. 청년 화자는 VOT가 겹치는 대신 F0를 함께 쓴다. 대립 자체는 유지된다. 무엇으로 유지하느냐가 바뀌었을 뿐이다.

§3.3에서 이것을 숫자로 확인한다.

3.2성조 발생 (tonogenesis) · tonogenesis

자음의 부수적 F0 효과　→　과장됨　→　학습자가 주된 단서로 재해석　→　성조화
  • 원래는 자음의 부산물이던 F0 차이가 일차적 대립이 되어 간다
  • 동아시아 여러 언어의 성조가 이런 경로로 생겨났다고 본다
  • 한국어가 지금 그 과정의 중간에 있다
학생에게

여러분은 언어 변화의 한복판에 있는 화자다. 오늘 잰 자기 데이터가 곧 이 변화의 증거다. 부모 세대와 비교하면 그 자체로 미니 연구가 된다 — 14주차 연구 트랙 주제로 좋다.

방언 차이도 있다

경상 방언은 성조를 가지고 있어 어두 F0 패턴이 서울말과 다르다. 이 경우 자음의 F0 단서와 어휘 성조가 겹쳐 해석이 복잡해진다. 실습에서 방언 배경 화자가 있으면 따로 표시해 두는 것이 좋다.

3.3병합을 어떻게 재나 ★ · quantifying merger

“겹친다”, “병합됐다”를 눈대중으로 말하면 사람마다 답이 다르다. 9주차에서 모음 합류에 Pillai 점수를 썼듯이, 여기에도 쓸 수 있는 도구가 있다.

① 두 분포가 얼마나 떨어져 있나 — Cohen의 d

Cohen d　d = (평균격음 − 평균평음) / 합동표준편차

단위가 없는 값이라 ms로 잰 VOT와 반음으로 잰 F0를 같은 자로 비교할 수 있다. 이것이 핵심이다 — 원래 단위 그대로는 “VOT 차이 20 ms”와 “F0 차이 2 반음” 중 어느 쪽이 큰지 말할 수 없다.

② 실제로 얼마나 겹치나 — 중첩 계수

중첩(OVL)　OVL = 2 · Φ( −|d| / 2 )　　(Φ = 표준정규 누적분포)

두 분포가 공유하는 면적의 비율이다. d만 알면 바로 나온다. d = 1이면 약 62 %가 겹치고, d = 4면 3 % 남짓만 겹친다.

③ 그래서 구별이 되나 — 분류 정확도

가장 직접적인 물음이다. 이 단서만 주면 세 계열을 맞힐 수 있는가? 집단 평균까지의 거리로 판정하는 간단한 분류기(선형판별)로 정확도를 낸다.

Python 세 지표를 한 번에
import numpy as np
from scipy.stats import norm

def cohen_d(a, b):
    n1, n2 = len(a), len(b)
    sp = np.sqrt(((n1-1)*a.var(ddof=1) + (n2-1)*b.var(ddof=1)) / (n1+n2-2))
    return (b.mean() - a.mean()) / sp

def overlap(a, b):
    """두 정규분포가 공유하는 면적의 비율 (0~1)"""
    return 2 * norm.cdf(-abs(cohen_d(a, b)) / 2)

def lda_accuracy(X, y):
    """X: (n,) 또는 (n, k) 배열. 집단 평균까지의 마할라노비스 거리로 분류."""
    X = X.reshape(-1, 1) if X.ndim == 1 else X
    cls = np.unique(y)
    Sw = np.zeros((X.shape[1], X.shape[1])); mus = []
    for c in cls:
        Xi = X[y == c]
        mus.append(Xi.mean(0))
        Sw += np.cov(Xi.T, ddof=1).reshape(X.shape[1], -1) * (len(Xi) - 1)
    Si = np.linalg.inv(Sw / (len(X) - len(cls)))
    pred = [cls[np.argmin([(x-m) @ Si @ (x-m) for m in mus])] for x in X]
    return float(np.mean(np.array(pred) == y))

    Python VOT와 후속 F0 자동 추출
    import os, glob
import numpy as np
import pandas as pd
import parselmouth
from parselmouth.praat import call

F0_WINDOW = 0.020          # 후속모음 시작 20 ms

def semitone(hz, ref=100.0):
    return 12 * np.log2(np.asarray(hz, dtype=float) / ref)

def extract(wav, textgrid, tier=1, gender="male"):
    snd = parselmouth.Sound(wav)
    tg  = parselmouth.read(textgrid)
    floor, ceiling = (75, 300) if gender == "male" else (100, 500)
    pitch = snd.to_pitch(pitch_floor=floor, pitch_ceiling=ceiling)

    rows = []
    for i in range(1, call(tg, "Get number of intervals", tier) + 1):
        lab = call(tg, "Get label of interval", tier, i).strip()
        if not lab:
            continue
        burst = call(tg, "Get start time of interval", tier, i)
        onset = call(tg, "Get end time of interval", tier, i)

        vals = [pitch.get_value_at_time(t) for t in
                np.arange(onset, min(onset + F0_WINDOW,
                                     snd.get_total_duration()), 0.005)]
        vals = [v for v in vals if v and not np.isnan(v)]
        f0 = float(np.mean(vals)) if vals else np.nan

        rows.append({"file": os.path.basename(wav), "label": lab,
                     "vot_ms": round((onset - burst) * 1000, 1),
                     "f0_Hz": round(f0, 1) if vals else np.nan,
                     "f0_st": round(semitone(f0), 2) if vals else np.nan})
    return rows

    VOT × F0 산점도에 신뢰타원을 그려라

    이렇게 시켜보자
    “VOT(ms)와 후속모음 F0를 담은 CSV를 읽어서, 발성유형(평음/경음/격음)별로 색을 달리한 산점도를 그려줘. F0는 반음으로 변환해서 세로축에 놓고 기준은 100 Hz로 해줘. 각 유형마다 95 % 신뢰타원을 함께 그리고, 유형별 평균 VOT와 평균 F0를 표로 출력해줘.”

    확인 방법 — 경음의 평균 VOT가 가장 짧고, 격음이 가장 길어야 한다. 평음의 평균 F0가 가장 낮아야 한다. 이 셋이 안 맞으면 라벨이 섞인 것이다.

    제출할 것 — 프롬프트 / 코드 / 고친 부분 / 산점도와 해석.

    이번 미션의 함정

    AI는 반음 변환을 빠뜨리고 Hz 그대로 그리는 일이 잦다. 남녀를 함께 그렸을 때 성별로 두 덩어리가 생기면 그 신호다.

    신뢰타원은 어떻게 그리는가 — 받은 코드를 검토하려면 알아야 한다

    AI가 그려주더라도 맞게 그렸는지 판단하려면 원리를 알아야 한다. 세 줄이면 된다.

    단계하는 일
    1그 집단의 공분산행렬 Σ를 구한다 (2 × 2)
    2Σ의 고윳값 λ₁, λ₂와 고유벡터를 구한다 — 고유벡터가 타원의 축 방향이다
    3반축 길이 = √(c · λ), 중심은 집단 평균
    c 값　95 % 타원 → χ²(0.95, 자유도 2) = 5.991
    　　　　　　(자유도 1의 3.841이 아니다 — 2차원이므로 2를 쓴다)
    Python 신뢰타원
    import numpy as np
from matplotlib.patches import Ellipse
from scipy.stats import chi2

def conf_ellipse(ax, x, y, p=0.95, **kw):
    S = np.cov(x, y)
    vals, vecs = np.linalg.eigh(S)          # 오름차순
    order = vals.argsort()[::-1]
    vals, vecs = vals[order], vecs[:, order]
    c = chi2.ppf(p, df=2)                   # 95% -> 5.991
    w, h = 2 * np.sqrt(c * vals)            # 지름 = 2 x 반축
    angle = np.degrees(np.arctan2(*vecs[:, 0][::-1]))
    ax.add_patch(Ellipse((x.mean(), y.mean()), w, h, angle=angle,
                         fill=False, **kw))
    자주 틀리는 두 가지

    ① 반축과 지름을 헷갈린다. matplotlib의 Ellipse는 지름을 받는다. √(cλ)를 그대로 넣으면 타원이 절반 크기로 그려진다.

    ② 자유도를 1로 쓴다. 3.841을 쓰면 95 %가 아니라 약 86 % 타원이 된다.

    눈으로 확인하는 법 — 95 % 타원이면 점의 약 20개 중 1개가 밖에 있어야 한다. 전부 안에 들어와 있으면 너무 크게 그린 것이다.

오늘 챙겨갈 여섯 문장

  1. VOT는 파열에서 성대 진동 개시까지의 시간이다.
  2. VOT는 발성 유형을 가르고, 조음 위치는 포먼트 전이가 가른다. 둘은 다른 축이다.
  3. 어느 단서가 가르는지는 분류 정확도로 답한다. 청년 세대는 VOT만으로도 F0만으로도 부족하고, 둘을 함께 써야 갈린다.
  4. 한국어 파열음 세 계열은 모두 무성이다. 유성/무성 대립이 아니다.
  5. VOT 하나로는 삼중대립이 갈라지지 않는다. 후속모음 F0가 함께 필요하다.
  6. 젊은 세대일수록 F0 의존도가 높다 — 지금도 변하는 대립이다.
  7. F0를 비교할 때는 반드시 반음으로 변환한다.

자주 나오는 질문

평음이 어중에서는 유성음으로 발음되지 않나요?

그렇다. 모음 사이에서 평음은 유성음화된다(예: ‘바보’의 두 번째 ㅂ). 오늘 다루는 것은 어두 위치의 대립이다. 위치를 명시하지 않으면 데이터가 섞인다.

왜 경음의 VOT가 가장 짧은가요?

성문을 강하게 닫은 채 조음하다가 파열과 거의 동시에 진동을 시작하기 때문이다. 성문이 이미 닫혀 있어 진동 개시가 빠르다.

외국인 학습자가 삼중대립을 어려워하는 이유는?

모국어에 없는 3계열 구분인 데다 단서가 VOT와 F0 둘로 분산되어 있기 때문이다. 특히 F0를 자음 단서로 쓰는 경험이 영어권 화자에게는 낯설다. 좋은 연구 주제다.

VOT 병합이 진행되면 평음과 격음이 안 갈리게 되나요?

아니다. 단서가 옮겨간 것이지 대립이 사라진 것이 아니다. VOT 대신 F0가 그 일을 한다.

파열이 두 번 보이면 어디를 기준으로 하나요?

연구마다 다르다. 첫 번째 파열을 기준으로 하고 그 사실을 적으면 된다. 일관성이 정답보다 중요하다.

평음과 격음의 VOT가 겹치면 어떻게 알아듣나요?

후속모음의 F0가 그 일을 대신한다. §3.3의 모형에서 청년 세대는 VOT만으로 76.7 %, F0만으로 70.0 %지만 둘을 함께 쓰면 99.2 %다. 청자는 이미 두 단서를 함께 쓰고 있다.

Cohen d가 얼마면 “병합”인가요?

9주차 Pillai와 마찬가지로 공인된 경계값이 없다. 관례적으로 d가 0.8이면 “큰 효과”라고 하지만, 그것이 “구별된다”는 뜻은 아니다. d = 1이어도 두 분포의 62 %가 겹친다. 세대끼리, 화자끼리 비교할 때 의미가 생긴다.

자동으로 잰 VOT를 문헌값과 바로 비교해도 되나요?

위험하다. §1.3에서 봤듯 검출 방법에 따라 3~13 ms가 밀린다. 평음–격음 병합을 논할 때 이 정도는 결코 작은 값이 아니다. 문헌이 손 라벨링이었다면 자기도 손으로 재야 비교가 성립한다.

경상 방언 화자의 데이터는 어떻게 하나요?

따로 표시해 두고 분석에서 분리한다. 어휘 성조가 어두 F0에 얹혀 자음의 F0 단서와 뒤섞이기 때문이다. 섞어서 평균 내면 두 효과가 상쇄되어 변화가 없는 것처럼 보인다.

VOT로 /바/ /다/ /가/ 를 구별할 수 있나요?

거의 못 한다. 조음 위치에 따른 VOT 차이는 수 ms 수준이라 화자 간·토큰 간 변이에 묻힌다. 조음 위치는 포먼트 전이가 가른다(§1.5). VOT가 가르는 것은 평음·경음·격음이다. 두 축은 서로 독립적이다.

전이를 재려는데 값이 이상합니다

창 길이부터 확인하라. 기본 25 ms로는 전이가 뭉개져 양순음이 치조음처럼 보인다(§1.5의 실측: 771 → 1553). window_length=0.010으로 줄이면 해결된다. 대신 주파수 해상도가 나빠지므로 정상 구간 측정에는 다시 기본값으로 돌아갈 것.
