§1청각의 주파수 분석

이론 20분 · 3주차와 5주차가 여기서 다시 만난다

1.1말초 청각

음파 → 외이도 → 고막 → 이소골 → 와우
외이도 공명 — 3주차 §2.5의 회수

길이가 약 2.5 cm인 한쪽만 열린 관이라 약 2.7 kHz에서 1/4파장 공명한다. 5주차 성도 공명과 완전히 같은 계산이다. 이것이 3–4 kHz에서 가장 예민한 이유다.

이소골의 역할 — 공기(저임피던스)에서 림프액(고임피던스)으로 에너지를 넘기려면 압력을 크게 키워야 한다. 고막과 등골 바닥의 면적 비와 지렛대 작용으로 약 30 dB를 번다.

1.2기저막 — 진행파 이론

위치성질반응하는 주파수

첨부 (꼭대기)넓고 부드럽다저주파
3주차 공식으로 설명된다

f = (1/2π)√(k/m)

뻣뻣하면(k↑) 고주파, 부드럽고 무거우면 저주파. 스스로 연결할 수 있어야 한다.

장소 부호화(place coding) — 어느 주파수가 들어왔는지가 어느 위치가 흔들렸는가로 표현된다. 와우는 일종의 실시간 스펙트럼 분석기다.

1.3임계대역과 청각 척도

기저막의 각 지점은 하나의 대역통과 필터처럼 작동한다. 그 폭이 임계대역이다.

  • 두 소리가 같은 임계대역 안에 있으면 서로 차폐(masking)한다
  • 3주차 맥놀이의 확장 — 주파수 차가 커지면 울렁임 → 거칠기 → 두 음으로 분리된다. 분리되는 지점이 대략 임계대역 폭이다
척도특징
Bark임계대역 1개 = 1 Bark. 총 24 Bark로 가청 범위를 덮는다
ERB등가직사각형대역폭. 최근 문헌에서 더 많이 쓴다
Mel음도의 등간격 척도. 음성인식의 MFCC가 이것을 쓴다
왜 배우는가

Hz는 물리의 척도이고, Bark는 귀의 척도다. 9주차 포먼트 정규화의 Bark 차이법, 11주차 스펙트럼 분석, 그리고 음성인식의 특징 추출이 전부 이 척도 위에서 이뤄진다.

2.4예측 판별 — 두 번째 조건을 실제로 재는 법 ★

§2.2에서 범주적 지각의 조건이 둘이라고 했다. 첫째(급격한 식별 곡선)는 로지스틱 적합으로 재면 된다. 그런데 둘째 — “판별이 식별로 예측된다”는 어떻게 재는가?

발상

식별 결과만 가지고 판별 성적을 미리 계산해 두고, 실제 판별 성적과 비교한다. 둘이 맞아떨어지면 “청자는 라벨만 듣고 판단한다” = 범주적이다.

계산은 간단하다. 자극 i와 j를 각각 “파”로 들을 확률을 pi, pj라 하자. 청자가 라벨이 다르면 “다르다”고 답하고, 같으면 찍는다고 가정하면

예측 판별　P = [pi(1−pj) + pj(1−pi)] + 0.5 · [pipj + (1−pi)(1−pj)]
　　　　　　　　앞쪽 = 라벨이 갈린 경우　　뒤쪽 = 라벨이 같아 찍는 경우
Python 예측 판별
def predicted_discrimination(p_i, p_j):
    """식별 확률 두 개로부터 판별 정답률을 예측한다."""
    different = p_i * (1 - p_j) + p_j * (1 - p_i)   # 라벨이 갈린다 -> 맞힌다
    same      = p_i * p_j + (1 - p_i) * (1 - p_j)   # 라벨이 같다 -> 찍는다
    return different + 0.5 * same

경계 35 ms로 고정하고 곡선의 가파름(s)만 바꿔가며 계산해 봤다.

여기서 놓치기 쉬운 것 — 봉우리는 셋 다 0.75다

봉우리 높이만 보면 세 청자가 구별되지 않는다. 공식상 최대가 0.75로 정해져 있기 때문이다. 범주성을 가르는 것은 “나머지가 얼마나 평평한가”다.

그래서 지표를 봉우리 − 가장자리로 잡는다. 강한 범주형은 0.25, 거의 연속형은 0.04다. “경계에서 잘 구별한다”가 아니라 “경계 밖에서 못 구별한다”가 범주적 지각의 핵심이다.

모음이 덜 범주적이라는 말의 뜻

§2.3에서 모음은 덜 범주적이라고 했다. 그것은 모음 연속체에서 경계 밖 판별 성적이 0.5로 떨어지지 않고 계속 높게 유지된다는 뜻이다. 같은 범주 안의 차이도 들린다. 위 표의 “거의 연속형”이 그 모습이다.

선행 문장을 빠르게 들려주면 같은 자극의 범주 경계가 이동한다. 경계는 고정된 물리값이 아니라 맥락에 따라 움직인다.

다중 단서와 상충(trading relation) — 하나의 대립에 여러 단서가 함께 기여하고 서로 보상한다. 10주차 한국어 삼중대립이 바로 그 예다. VOT가 약하면 F0가 그 일을 대신한다.

3.4말 명료도 — 지각 연구가 임상과 만나는 곳 ★

지금까지 지각을 실험실 과제로 다뤘다. 임상에서 가장 중요한 지각 변수는 따로 있다. 말 명료도(speech intelligibility) — 청자가 알아들을 수 있는가다.

왜 이것이 최종 변수인가

음성장애·마비말장애·조음장애의 치료 목표는 결국 “알아듣게 하는 것”이다. jitter가 줄고 VSA가 넓어져도 알아듣지 못하면 의미가 없다. 그래서 명료도는 다른 지표들의 준거 변수 역할을 한다.

구분무엇을 재나주의
명료도 (intelligibility)말소리를 정확히 알아들었는가 — 단어·음소 단위맥락 없이 잰다
이해도 (comprehensibility)맥락·몸짓·상황을 포함해 의미가 전달되는가실생활에 더 가깝다
용인도 (acceptability)듣기에 자연스러운가명료해도 낮을 수 있다

실생활의 듣기는 언제나 소음 속에서 일어난다. 신호대잡음비(SNR)를 조절하며 재면 조용한 곳에서는 안 보이던 차이가 드러난다.

§2의 범주적 지각과 이어진다

소음이 섞이면 범주 경계가 흐려지고 식별 곡선이 완만해진다. §2.4의 용어로 하면 s가 커지는 것이다. 오늘 만든 연속체에 소음을 섞어 다시 실험하면 같은 청자에게서 그 변화를 직접 볼 수 있다 — 시간이 남는 조에게 권할 만한 확장이다.

    Python VOT 연속체 합성
    import os
import numpy as np
import pandas as pd
import parselmouth
from parselmouth.praat import call

def make_vot_continuum(out_dir="continuum", steps=9,
                       vot_min=0.005, vot_max=0.085,
                       f0=120, vowel=(730, 1090, 2440), vowel_dur=0.30):
    """모음 부분은 한 번만 합성해 모든 단계가 공유한다 — VOT만 달라지게."""
    os.makedirs(out_dir, exist_ok=True)
    rng = np.random.default_rng(0)

    kg = call("Create KlattGrid", "v", 0, vowel_dur, 6, 1, 1, 6, 1, 1, 1)
    call(kg, "Add pitch point", vowel_dur / 2, f0)
    call(kg, "Add voicing amplitude point", vowel_dur / 2, 90)
    for i, (f, b) in enumerate(zip(vowel, (60, 90, 150)), start=1):
        call(kg, "Add oral formant frequency point", i, vowel_dur / 2, f)
        call(kg, "Add oral formant bandwidth point", i, vowel_dur / 2, b)
    v = call(kg, "To Sound")
    sr  = v.sampling_frequency
    v_x = v.values[0] / np.max(np.abs(v.values[0])) * 0.8

    rows = []
    for k, vot in enumerate(np.linspace(vot_min, vot_max, steps), start=1):
        n = int(vot * sr)
        burst = rng.normal(0, 0.12, n) * np.linspace(1.0, 0.35, n)
        name = f"vot{k:02d}"
        parselmouth.Sound(np.concatenate([burst, v_x]),
                          sampling_frequency=sr).save(f"{out_dir}/{name}.wav", "WAV")
        rows.append({"step": k, "stimulus": name, "vot_ms": round(vot * 1000, 1)})

    df = pd.DataFrame(rows)
    df.to_csv(f"{out_dir}/stimuli.csv", index=False, encoding="utf-8-sig")
    return df

    Python 로지스틱 적합으로 범주 경계 구하기
    import numpy as np
import pandas as pd
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

def logistic(x, b, s):
    return 1.0 / (1.0 + np.exp(-(x - b) / s))

def fit_identification(df, x="vot_ms", y="p_response"):
    xs, ys = df[x].to_numpy(float), df[y].to_numpy(float)
    (b, s), _ = curve_fit(logistic, xs, ys,
                          p0=[xs.mean(), (xs.max() - xs.min()) / 10], maxfev=20000)
    return {"boundary_ms": round(float(b), 1),
            "slope_per_ms": round(1.0 / (4.0 * abs(s)), 4)}

resp = pd.read_csv("responses.csv")       # stimulus, response
stim = pd.read_csv("continuum/stimuli.csv")
resp["hit"] = (resp["response"] == "파").astype(int)
g = resp.groupby("stimulus")["hit"].mean().rename("p_response").reset_index()
d = stim.merge(g, on="stimulus").sort_values("step")

fit = fit_identification(d)
print(f"범주 경계 = {fit['boundary_ms']} ms,  기울기 = {fit['slope_per_ms']} /ms")

xs = np.linspace(d.vot_ms.min(), d.vot_ms.max(), 200)
plt.figure(figsize=(5.5, 4))
plt.plot(d.vot_ms, d.p_response, "o")
plt.plot(xs, logistic(xs, fit["boundary_ms"], 1 / (4 * fit["slope_per_ms"])))
plt.axvline(fit["boundary_ms"], ls="--", color="gray")
plt.xlabel("VOT (ms)"); plt.ylabel("p(아스피레이션 응답)"); plt.ylim(-.05, 1.05)
plt.tight_layout(); plt.show()
    Python 예측 판별과 관찰 판별 비교
    import numpy as np
import matplotlib.pyplot as plt

def predicted_discrimination(p_i, p_j):
    return (p_i*(1-p_j) + p_j*(1-p_i)) + 0.5*(p_i*p_j + (1-p_i)*(1-p_j))

# ident: 자극 단계별 "파" 응답 비율 (식별 실험 결과)
# obs  : 두 칸 떨어진 쌍의 관찰 판별 정답률 (판별 실험 결과)
pred = [predicted_discrimination(ident[i], ident[i+2])
        for i in range(len(ident) - 2)]

    이번 미션의 함정

    로지스틱 적합은 초기값에 민감하다. AI가 초기값을 안 주거나 엉뚱하게 주면 수렴하지 않거나 말이 안 되는 값을 낸다. 경계가 자극 범위 안에 있는지가 그 검사다.

    예측 판별까지 시킨다면 함정이 하나 더 있다. AI는 “라벨이 같으면 찍는다” 항(0.5 × …)을 빠뜨리는 일이 잦다. 그러면 경계에서 먼 곳의 예측이 0.5가 아니라 0으로 떨어진다. 가장자리 값이 0.5 근처인지가 검사다.

SRT　　　50 % 정답률이 되는 SNR. 낮을수록 소음에 강하다

오늘 챙겨갈 여섯 문장

  1. 와우는 위치로 주파수를 부호화하는 실시간 분석기다.
  2. Hz는 물리의 척도, Bark는 귀의 척도다.
  3. 범주적 지각 — 물리적으로 같은 차이도 경계를 넘느냐에 따라 다르게 들린다.
  4. 같은 음소가 매번 물리적으로 다르다. 청자는 실시간으로 정규화한다.
  5. 범주 경계는 고정된 값이 아니라 맥락에 따라 이동한다.
  6. 명료도는 화자만의 속성이 아니다. 청자·과제·소음이 함께 정한다.
  7. 식별만 재고 범주적 지각이라고 하면 안 된다. 판별을 함께 재고 예측과 맞춰봐야 한다.

자주 나오는 질문

식별 곡선이 급격하면 범주적 지각 아닌가요?

그것은 첫째 조건일 뿐이다. 둘째 조건 — 같은 범주 안의 차이를 못 듣는가 — 를 확인하려면 판별 실험이 따로 필요하다. 식별이 급격한데 판별은 어디서나 잘하는 청자도 있다. 그 경우 범주적이라고 할 수 없다.

예측 판별의 봉우리가 왜 항상 0.75인가요?

공식의 구조 때문이다. 경계에서 한 자극은 확실히 “바”, 다른 하나는 확실히 “파”로 들리면 라벨이 100 % 갈려 정답률이 1.0이 되어야 할 것 같지만, 실제로는 경계에 걸친 자극의 라벨이 확률적이라 그 최댓값이 0.75로 묶인다. 그래서 봉우리 높이로는 청자를 구별할 수 없고, 가장자리를 봐야 한다.

관찰 판별이 예측보다 계속 높게 나왔는데 실험을 잘못한 건가요?

아닐 가능성이 높다. 가장 흔한 결과다. 순수한 범주적 지각은 이상화된 모형이고, 실제 청자는 라벨과 음향 정보를 둘 다 쓴다. ISI를 짧게 잡았다면 더 그렇다. 발견으로 보고하면 된다.

범주적 지각이 타고난 건가요, 배운 건가요?

둘 다다. 영아는 여러 대립을 구별할 능력을 갖고 태어나지만 첫 해에 모국어에 맞춰 조정된다. 그리고 성인이 되어서도 훈련으로 어느 정도 바뀐다.

모음은 왜 범주적으로 안 들리나요?

정상 상태가 길어 계속 비교할 수 있고 청각 기억에 잔상이 남기 때문이다. 파열음의 전이는 수십 ms 안에 끝나 그럴 여유가 없다.

McGurk 효과가 안 보이는 사람도 있나요?

있다. 개인차와 언어권 차이가 보고된다. 자극 품질에도 민감해서 실험 조건을 잘 통제해야 한다.

인공와우 사용자는 말을 어떻게 알아듣나요?

주파수 해상도가 크게 줄어 포먼트 세부는 잃지만 시간 포락선 정보가 상당히 보존되어 조용한 환경에서는 이해가 가능하다. 소음 환경과 음악에서 어려움이 크다.

실험에서 제 경계값이 친구와 다른데 잘못한 건가요?

아니다. 개인차는 정상이다. 방언·연령·경험에 따라 다르다. 오히려 그 차이가 흥미로운 결과다.

명료도와 이해도가 어떻게 다른가요?

명료도는 맥락 없이 말소리 자체를 알아듣는 정도이고, 이해도는 맥락·몸짓·상황을 포함해 의미가 전달되는 정도다. 명료도가 낮아도 이해도는 높을 수 있다 — 가족과의 대화가 그렇다. 치료 목표를 어느 쪽으로 잡느냐가 달라진다.

명료도를 재는데 청자마다 점수가 너무 다릅니다

정상이다. 청자의 친숙도가 가장 큰 변수다. 같은 화자라도 가족이 들으면 훨씬 높게 나온다. 낯선 청자 여러 명의 평균을 쓰고, 청자 조건을 반드시 기록한다. 7주차 §4.4의 평정자 신뢰도 문제와 같은 구조다.
