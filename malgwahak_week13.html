1.1말초 청각 · the peripheral auditory system

음파 → 외이도 → 고막 → 이소골 → 와우
외이도 공명 — 3주차 §2.5의 회수

외이도는 길이 약 2.5 cm에 한쪽 끝이 고막으로 막힌 관이다. 그래서 5주차에서 성도 공명을 구할 때와 같은 1/4파장 공식 c/4L을 그대로 쓸 수 있다. 20 ℃의 음속 343 m/s를 넣으면 약 3.4 kHz가 나온다. 실제 귀에서 재는 공명 봉우리는 이보다 낮은 3 kHz 안팎(교과서에 따라 2.7 kHz)으로 소개되는데, 위 계산이 외이도를 끝이 단단히 막힌 곧은 원통으로 단순화한 것이기 때문이다. 사람의 귀가 3–4 kHz 근처에서 가장 예민한 이유의 하나가 이 공명이다.

이소골은 공기(저임피던스)에서 림프액(고임피던스)으로 에너지를 넘기는 일을 한다. 그대로 두면 대부분의 에너지가 반사되므로 압력을 크게 키워야 하는데, 고막과 등골 바닥의 면적 비와 지렛대 작용으로 약 30 dB를 번다.

2.4예측 판별 — 두 번째 조건을 실제로 재는 법 ★ · predicted discrimination

§2.2에서 범주적 지각의 조건이 둘이라고 했다. 첫째 조건인 급격한 식별 곡선은 로지스틱 적합으로 재면 된다. 그렇다면 둘째 조건, 판별이 식별로 예측된다는 것은 어떻게 재는가.

발상

식별 결과만 가지고 판별 성적을 미리 계산해 두고, 실제 판별 성적과 비교한다. 둘이 맞아떨어지면 청자는 소리의 라벨만 듣고 판단하고 있다는 뜻이고, 그것이 곧 범주적 지각이다.

계산은 간단하다. 자극 i와 j를 각각 “파”로 들을 확률을 pi, pj라 하자. 청자가 두 소리에 붙인 라벨이 다르면 “다르다”고 답하고, 라벨이 같으면 반반으로 찍는다고 가정하면 판별 정답률은 아래와 같다.

예측 판별　P = [pi(1−pj) + pj(1−pi)] + 0.5 · [pipj + (1−pi)(1−pj)]
　　　　　　　　앞쪽 = 라벨이 갈린 경우　　뒤쪽 = 라벨이 같아 찍는 경우
Python 예측 판별
def predicted_discrimination(p_i, p_j):
    """식별 확률 두 개로부터 판별 정답률을 예측한다."""
    different = p_i * (1 - p_j) + p_j * (1 - p_i)   # 라벨이 갈린다 -> 맞힌다
    same      = p_i * p_j + (1 - p_i) * (1 - p_j)   # 라벨이 같다 -> 찍는다
    return different + 0.5 * same

이 계산에서는 경계 35 ms가 마침 ④번 자극과 정확히 겹친다. ④번의 p가 0.5이면 공식의 앞쪽과 뒤쪽이 모두 0.5가 되어, 짝이 되는 자극이 무엇이든 P = 0.5 + 0.5 × 0.5 = 0.75가 된다. 그래서 세 청자의 봉우리가 똑같이 0.75로 나온 것이다. 0.75가 공식의 최댓값은 아니다. 두 자극의 p가 0과 1로 완전히 갈리면 P는 1.0까지 올라가고, 실습 A3에서 보듯 쌍의 간격을 두 칸으로 넓히면 강한 범주형 청자의 봉우리는 0.97이 된다. 그림 2의 판별 곡선이 0.98까지 솟는 것도 같은 이유다.

그래서 봉우리 높이는 쌍의 간격과 경계의 위치에 따라 달라지는 값이고, 범주성을 판단할 때는 경계에서 먼 쌍, 곧 가장자리가 얼마나 0.5에 가까운지를 함께 봐야 한다. 지표를 봉우리 − 가장자리로 잡는 이유다. 위 표에서 강한 범주형은 0.25, 거의 연속형은 0.04다. 경계에서 잘 구별한다는 것보다 경계 밖에서 잘 구별하지 못한다는 것이 범주적 지각을 더 잘 드러낸다.

모음이 덜 범주적이라는 말의 뜻

§2.3에서 모음은 덜 범주적이라고 했다. 이것은 모음 연속체에서 경계 밖의 판별 성적이 0.5로 떨어지지 않고 계속 높게 유지된다는 뜻이다. 같은 범주 안의 차이도 들린다는 것이며, 위 표의 거의 연속형이 그런 모습이다.

  • 다만 완전히 굳는 것은 아니어서, 훈련으로 상당 부분 회복된다.

앞선 문장을 빠르게 들려주면 같은 자극의 범주 경계가 이동한다. 경계는 고정된 물리값이 아니라 맥락에 따라 움직인다.

하나의 대립에는 여러 단서가 함께 기여하고, 한 단서가 약하면 다른 단서가 그 몫을 메운다. 이를 단서 간 상충 관계(trading relation)라고 한다. 10주차의 한국어 삼중대립이 바로 그 예로, VOT가 약하면 F0가 그 일을 대신한다. 실습 B2에서 실제 녹음으로 연속체를 만들면 이 문제와 직접 마주친다.

조음 동작을 지각한다고 보는 입장에는 운동이론 말고도 직접 실재론(direct realism)이 있다. 직접 실재론은 말소리 전용 모듈을 가정하지 않고, 청자가 음향 신호를 통해 조음 몸짓을 직접 지각한다고 본다.

McGurk 효과

/바/ 소리에 /가/ 입모양을 함께 보여 주면 /다/로 들린다. 시각 정보가 청각 지각을 바꾸는 것이다. 지각은 귀만의 일이 아니다.

3.4말 명료도 — 지각 연구가 임상과 만나는 곳 ★ · speech intelligibility

지금까지는 지각을 실험실 과제로 다뤘다. 임상에서 가장 중요한 지각 변수는 따로 있는데, 청자가 그 말을 알아들을 수 있는가를 나타내는 말 명료도(speech intelligibility)다.

왜 이것이 최종 변수인가

음성장애, 마비말장애, 조음장애의 치료 목표는 결국 알아듣게 하는 것이다. jitter가 줄고 VSA가 넓어져도 알아듣지 못하면 의미가 없다. 그래서 명료도는 다른 지표들을 평가하는 준거 변수 역할을 한다.

구분무엇을 재나주의
명료도 (intelligibility)말소리를 정확히 알아들었는가 — 단어·음소 단위맥락 없이 잰다
이해도 (comprehensibility)맥락·몸짓·상황을 포함해 의미가 전달되는가실생활에 더 가깝다

  1. A1연속체 점검 — 정말 VOT만 달라졌나 · 15분

    범주적 지각 실험에서 가장 먼저 확인할 것은 자극의 통제다. 아홉 소리가 VOT만 다르고 나머지는 모두 같아야 청자의 응답 변화를 VOT 탓으로 돌릴 수 있다. 아래가 연속체를 만든 코드다. 모음은 한 번만 합성해 아홉 단계가 함께 쓰고, 앞에 붙이는 기식 잡음의 길이만 바꾼다.

    Python VOT 연속체 합성
    import os
import numpy as np
import pandas as pd
import parselmouth
from parselmouth.praat import call

def make_vot_continuum(out_dir="continuum", steps=9,
                       vot_min=0.005, vot_max=0.085,
                       f0=120, vowel=(730, 1090, 2440), vowel_dur=0.30, sr=22050):
    """모음 부분은 한 번만 합성해 모든 단계가 공유한다 — VOT만 달라지게."""
    os.makedirs(out_dir, exist_ok=True)
    rng = np.random.default_rng(0)

    # KlattGrid는 오라 포먼트 6개를 갖고 만들어진다. 6개를 모두 지정해야 F2·F3가 오염되지 않는다
    freqs = list(vowel) + [3500, 4500, 5500]
    bws   = [60, 90, 150, 200, 250, 300]
    kg = call("Create KlattGrid", "v", 0, vowel_dur, 6, 1, 1, 6, 1, 1, 1)
    call(kg, "Add pitch point", vowel_dur / 2, f0)
    call(kg, "Add voicing amplitude point", vowel_dur / 2, 90)
    for i, (f, b) in enumerate(zip(freqs, bws), start=1):
        call(kg, "Add oral formant frequency point", i, vowel_dur / 2, f)
        call(kg, "Add oral formant bandwidth point", i, vowel_dur / 2, b)
    v = call(call(kg, "To Sound"), "Resample", sr, 50)
    v_x = v.values[0] / np.max(np.abs(v.values[0])) * 0.8
    fade = int(0.02 * sr)
    v_x[-fade:] *= np.linspace(1, 0, fade)          # 끝 20 ms 페이드

    rows = []
    for k, vot in enumerate(np.linspace(vot_min, vot_max, steps), start=1):
        n = int(round(vot * sr))
        burst = rng.normal(0, 0.12, n) * np.linspace(1.0, 0.35, n)
        name = f"vot{k:02d}"
        parselmouth.Sound(np.concatenate([burst, v_x]),
                          sampling_frequency=sr).save(f"{out_dir}/{name}.wav", "WAV")
        rows.append({"step": k, "stimulus": name, "vot_ms": round(vot * 1000, 1)})

    df = pd.DataFrame(rows)
    df.to_csv(f"{out_dir}/stimuli.csv", index=False, encoding="utf-8-sig")
    return df

  2. A2식별 곡선 적합 — 가상 청자의 경계를 찾아라 · 15분

    responses_sim.csv는 가상 청자 여섯 명이 아홉 자극을 각각 20번씩 듣고 “바” 또는 “파”라고 답한 자료다. 각 청자는 정해진 경계와 가파름을 갖도록 만들었고, 그중 한 명에게는 따로 정해 둔 특징이 있다. 참값은 정답 상자에만 적어 두었다.

    Python 청자별 로지스틱 적합
    import numpy as np
import pandas as pd
from scipy.optimize import curve_fit

def logistic(x, b, s):
    return 1.0 / (1.0 + np.exp(-(x - b) / s))

def fit_identification(df, x="vot_ms", y="p_response"):
    xs, ys = df[x].to_numpy(float), df[y].to_numpy(float)
    (b, s), _ = curve_fit(logistic, xs, ys,
                          p0=[xs.mean(), (xs.max() - xs.min()) / 10], maxfev=20000)
    return {"boundary_ms": round(float(b), 1),
            "slope_per_ms": round(float(1.0 / (4.0 * abs(s))), 4)}

resp = pd.read_csv("responses_sim.csv")          # subject, stimulus, response
stim = pd.read_csv("continuum/stimuli.csv")      # step, stimulus, vot_ms
resp["hit"] = (resp["response"] == "파").astype(int)

for subj, r in resp.groupby("subject"):          # 청자마다 따로 적합한다
    g = r.groupby("stimulus")["hit"].mean().rename("p_response").reset_index()
    d = stim.merge(g, on="stimulus").sort_values("step")
    fit = fit_identification(d)
    print(subj, fit, "  p =", d.p_response.round(2).tolist())

  3. A3예측 판별과 관찰 판별 — 식별만으로는 알 수 없는 것 · 15분

import numpy as np
import parselmouth

def shorten_aspiration(wav, burst_t, voice_t, targets_ms, out_head="real_vot", keep_ms=5, fade_ms=2):
    """격음 하나의 기식 구간 가운데를 잘라 내어 VOT가 targets_ms인 소리들을 만든다.
       burst_t: 파열 시각(초), voice_t: 성대 진동 시작 시각(초) — 편집 창에서 직접 읽는다."""
    snd = parselmouth.Sound(wav)
    sr, x = snd.sampling_frequency, snd.values[0]
    b, v = int(round(burst_t * sr)), int(round(voice_t * sr))
    keep, f = int(keep_ms / 1000 * sr), int(fade_ms / 1000 * sr)
    for k, target in enumerate(targets_ms, start=1):
        remove = (v - b) - int(round(target / 1000 * sr))      # 잘라 낼 표본 수
        if remove < 0 or target < keep_ms:
            raise ValueError(f"{target} ms는 만들 수 없다 (원래 VOT {(v - b) / sr * 1000:.1f} ms)")
        c0 = b + keep                                          # 파열 직후 keep_ms는 남긴다
        c1 = c0 + remove
        ramp = np.linspace(1, 0, f)
        joint = x[c0 - f:c0] * ramp + x[c1 - f:c1] * ramp[::-1]  # 이음매를 2 ms 교차 페이드
        y = np.concatenate([x[:c0 - f], joint, x[c1:]])
        parselmouth.Sound(y, sampling_frequency=sr).save(f"{out_head}{k:02d}.wav", "WAV")

# 예: 파열 0.512 s, 성대 진동 시작 0.596 s인 /파/에서 VOT 5~85 ms 아홉 단계

  3. 범주적 지각에서는 물리적으로 같은 차이도 경계를 넘느냐에 따라 다르게 들린다.
  4. 같은 음소가 매번 물리적으로 다르며, 청자는 이를 실시간으로 정규화한다.
  5. 범주 경계는 고정된 값이 아니라 맥락과 단서 조합에 따라 이동한다.
  6. 명료도는 화자만의 속성이 아니다. 청자, 과제, 소음이 함께 정한다.
  7. 식별만 재고 범주적 지각이라고 하면 안 된다. 판별을 함께 재고 예측과 맞춰 봐야 하며, 그 분석 코드는 먼저 참값을 아는 가상 청자로 검증한다.

자주 나오는 질문

가상 청자로 연습하는 것이 실제 실험에 도움이 되나요?

분석 절차를 검증하는 데는 가장 확실한 방법이다. 경계와 가파름을 알고 만든 응답이니 코드가 경계를 제대로 찾는지, 예측 판별 공식을 바르게 옮겼는지가 바로 드러난다. 다만 가상 청자는 정해 둔 규칙대로만 답하므로 지각에 대해 새로 알려 주는 것은 없다. 실제 청자의 피로, 응답 편향, 방언 차이 같은 문제는 실습 B에서만 만난다.

식별 곡선이 급격하면 범주적 지각 아닌가요?

그것은 첫째 조건일 뿐이다. 같은 범주 안의 차이를 듣지 못하는지라는 둘째 조건은 판별 실험을 따로 해야 확인할 수 있다. 실습 A3의 S2처럼 식별은 급격한데 판별은 어디서나 잘하는 청자도 있고, 그런 경우에는 범주적이라고 할 수 없다.

§2.4 표의 봉우리는 왜 모두 0.75인가요?

그 표가 이웃한 두 자극(한 칸 쌍)으로 계산했고, 경계 35 ms가 마침 ④번 자극과 겹쳤기 때문이다. 한 자극의 p가 0.5이면 짝이 무엇이든 예측값이 0.75가 된다. 0.75가 공식의 최댓값은 아니어서, 두 칸 쌍으로 계산하면 강한 범주형 청자의 봉우리는 0.97까지 오른다(A3). 봉우리 높이는 이런 조건에 따라 바뀌므로 범주성은 가장자리를 함께 보고 판단한다.

관찰 판별이 예측보다 계속 높게 나왔는데 실험을 잘못한 건가요?

아닐 가능성이 크다. 실제 청자에게서 가장 흔한 결과다. 순수한 범주적 지각은 이상화된 모형이고, 실제 청자는 라벨과 음향 정보를 둘 다 쓴다. ISI를 짧게 잡았다면 더 그렇다. 발견으로 보고하면 된다.

반 친구들의 경계가 서로 10 ms 넘게 다릅니다. 실험이 잘못된 건가요?

꼭 그렇지는 않다. 개인차는 정상이고 방언, 연령, 경험에 따라 달라진다. 다만 자극마다 3번씩만 들은 자료라면 같은 사람도 다시 하면 몇 ms씩 달라질 수 있다(A4). 개인차라고 해석하기 전에 반복 횟수를 늘려 같은 사람의 경계가 얼마나 안정적인지 먼저 확인하는 편이 안전하다.

실제 /파/로 만든 연속체에서 짧은 단계가 /빠/로 들립니다.

예상할 수 있는 결과다. 기식만 줄이고 모음의 높은 F0는 그대로 남았기 때문에, 짧은 VOT와 높은 F0라는 경음 쪽 단서 조합이 된 것이다(10주차). 실패가 아니라 단서 간 상충 관계를 보여 주는 결과이니, 응답 보기를 세 개로 늘리거나 /바/를 바탕으로 만든 연속체와 비교해 보고서에 적는다.

범주적 지각이 타고난 건가요, 배운 건가요?

둘 다다. 영아는 여러 대립을 구별할 능력을 갖고 태어나지만 첫 해에 모국어에 맞춰 조정된다. 성인이 되어서도 훈련으로 어느 정도 바뀐다.

모음은 왜 범주적으로 들리지 않나요?

정상 상태가 길어 두 소리를 계속 비교할 수 있고 청각 기억에 잔상이 남기 때문이다. 파열음의 전이는 수십 ms 안에 끝나 그럴 여유가 없다. 그래도 B1에서 보듯 자연 모음의 식별이 늘 깔끔하게 갈리는 것은 아니다.

McGurk 효과가 안 보이는 사람도 있나요?

있다. 개인차와 언어권 차이가 보고된다. 자극 품질에도 민감해서 실험 조건을 잘 통제해야 한다.

인공와우 사용자는 말을 어떻게 알아듣나요?

주파수 해상도가 크게 줄어 포먼트의 세부는 잃지만 시간 포락선 정보가 상당히 보존되어, 조용한 환경에서는 이해가 가능하다. 소음 환경과 음악에서 어려움이 크다.

명료도와 이해도가 어떻게 다른가요?

명료도는 맥락 없이 말소리 자체를 알아듣는 정도이고, 이해도는 맥락·몸짓·상황을 포함해 의미가 전달되는 정도다. 명료도가 낮아도 이해도는 높을 수 있는데, 가족과의 대화가 그렇다. 치료 목표를 어느 쪽으로 잡느냐가 달라진다.

명료도를 재는데 청자마다 점수가 너무 다릅니다.

정상이다. 청자의 친숙도가 가장 큰 변수여서, 같은 화자라도 가족이 들으면 훨씬 높게 나온다. 낯선 청자 여러 명의 평균을 쓰고 청자 조건을 반드시 기록한다. 7주차 §4.4의 평정자 신뢰도 문제와 같은 구조다.
